Project Progress

Where the project stands, what shipped recently, and what is still being decided. The source of truth is the milestones on GitHub. This page is a summary of them.

Last updated Oct 29, 2026

At a Glance

  • PowerPoint is working end to end. Titles go first in the reading order, missing alt text is written, missing language is detected, and small text is reported. Both the website and the folder script work.
  • PDFs are now accepted. They are routed page by page and rebuilt as tagged PDFs. Scanned pages use OCR and always go to a person for review.
  • Not deployed yet, and there is no login. Visitors are kept apart only by a signed browser cookie. University sign-in is planned.
  • The alt-text model is still undecided. The main branch runs a local model (about 4.4 GB). A branch that switches to Claude on Amazon Bedrock is waiting for a decision.

Recently Shipped

  • PDF remediation (Oct 26). Uploaded PDFs go through a page-by-page pipeline and come back as tagged PDFs, with OCR for scanned pages and human review for anything uncertain. #84, #92
  • Presentation language (Oct 11). Missing, invalid or mixed language settings are reported, and can be set across the whole deck. #24
  • Minimum font size (Oct 11). Text below 9 pt is reported by slide, including sizes inherited from layouts and masters. #26
  • Title detection by layout (Oct 10). When a slide has no real title placeholder, a small trained model picks the likely title from size, position and wording. #7, #23
  • Documentation (Oct 10). A WCAG 2.1 coverage table, notes on exporting fixed decks to PDF, and a decision on Prezi (export to PowerPoint first). #50, #37

Open Decisions

  • Local model or hosted API for alt text. A local model needs a GPU machine and about 4.4 GB of files. A hosted API runs on a lighter server but costs money per image. #97
  • Whether n8n should orchestrate the pipeline, which affects how notifications and storage are built. #80
  • How to check web pages for problems that only show once rendered, such as CSS contrast and keyboard access. #47
