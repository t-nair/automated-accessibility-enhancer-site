Automated Accessibility Enhancer

An open-source tool that fixes common accessibility problems in PowerPoint files. It puts slide titles first in the reading order, adds alt text to images that don't have any, and creates a report of every change.

How It Works

The tool is written in Python and uses python-pptx to edit files directly. Files can come in three ways, and all of them go through the same pipeline.

Input

  • Web uploadFlask site
  • Folderz_reorder.py
  • S3 bucketAWS Lambda, not merged yet

Pipeline

  1. ConvertOlder .ppt files are converted to .pptx with LibreOffice
  2. Fix reading orderShapes named "Title" are moved to the front
  3. Add alt textImages without alt text are described by a vision model running locally

Output

  • Fixed .pptxReady to download
  • ReportEvery change, slide by slide

Current Limitations

  • Title detection can miss unusual layouts. When a slide has no real title placeholder, a small trained model guesses the title from size, position and wording. A title that is an image is not found.
  • Generated alt text needs to be reviewed. Models can get names, dates, and text inside diagrams wrong. The report lists every description so they can be checked.
  • Technical diagrams are hard to describe. Earlier tests with free tools like alternat did not produce usable alt text for engineering figures.
  • The alt-text model is large. It is about 4.4 GB and slow without a GPU. A hosted model is being considered (#97).
  • There are no user accounts. Files are kept separate with a signed browser cookie, which is not real security.
  • Files are processed one at a time, and progress is stored in memory. If the server restarts during a run, that file stays marked as processing.
